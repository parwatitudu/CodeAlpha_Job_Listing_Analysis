# Job Listing Analysis

## Overview
This project is a Job Listing Analysis project created using Python. 
The project collects job listing data from a website using web scraping techniques and performs data analysis and visualization.

## Features
- Web scraping using BeautifulSoup and Requests
- Data cleaning and processing using Pandas
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib
- Exported scraped data into CSV format

## Technologies Used
- Python
- BeautifulSoup
- Requests
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Collected job listing data from website
2. Parsed HTML content using BeautifulSoup
3. Stored data in Pandas DataFrame
4. Cleaned and analyzed the dataset
5. Created visualizations and insights
6. Exported data into CSV file

## Visualizations
- Bar Chart
- Horizontal Bar Chart
- Pie Chart

## Key Insights
- Identified top hiring companies
- Found most common job roles
- Analyzed top job locations
- Visualized job distribution patterns
